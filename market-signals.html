How It Works
Methodology

Autocorrelation Regression

For each ETF, a rolling 60-day OLS regression tests whether past returns predict future returns. The β coefficient is the autocorrelation at each lag.

r_{t+1} = α + β · r_t + ε

Regime Detection

The sign of β encodes the return regime. β₁ < 0 indicates short-term mean reversion — common in large-cap indices. β₁ > 0 indicates momentum continuation.

β < −0.08 → Reversion · β > 0.08 → Momentum

Signal Generation

Tomorrow's predicted return is computed from today's observed returns. When both 1-day and 5-day regressions agree, they are weighted by their t-statistics.

pred = α̂ + β̂ · r_today · w(|t|)
